AI-assisted development

I use AI coding agents as part of my everyday Unity workflow. I connect Claude Code to the Unity Editor through Unity MCP, so it can inspect scenes and GameObjects, write and refactor C# scripts, and read console errors. Through the Unity CLI it can also run builds and tests to check its own changes. I own the architecture and review every change, while the agent handles the repetitive work. That makes prototyping, debugging and refactoring much faster. I also use AI to sketch system designs as Mermaid diagrams before writing code.

Currently exploring: retrieval-augmented generation (RAG) pipelines.
